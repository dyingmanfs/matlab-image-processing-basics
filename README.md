# MATLAB Image Processing Basics

A collection of MATLAB exercises focused on fundamental **spatial-domain image processing techniques** including noise removal, edge detection, sharpening, histogram analysis, and basic image merging.

This project was developed as part of **CNG466 – Fundamentals of Image Processing** at METU NCC.

## Overview

The project contains four MATLAB scripts:

- Noise removal using median filtering
- Denoising and Sobel edge detection
- Spatial sharpening
- Basic image merging
